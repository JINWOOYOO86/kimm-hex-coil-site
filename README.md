# KIMM-HEX Coil 소개 페이지

한국기계연구원 히트펌프연구센터 **KIMM-HEX Coil** (핀튜브 열교환기 설계·성능예측 프로그램)
소개 페이지입니다. 판형·토큰은 구 `koilforge-site` 를 그대로 승계하고 **내용만** 현행
제품명·프로그램 기준으로 갱신했습니다(2026-09-03).

- `index.html` — 데스크톱 판. 단일 파일 정적 페이지 (제3자 스크립트·웹폰트·추적 도구 없음)
- `m.html` — **모바일 판**. 한 열·큰 터치 영역·짧은 스크롤. 문구와 이미지는 데스크톱 판과 같다
  (⚠️ 수치·문구를 고치면 **두 파일을 함께** 고칠 것 — 갈라지면 어느 쪽이 맞는지 알 수 없다)
- `assets/` — 화면 캡처(WebP) · KIMM 로고(SVG) · 제품 마크(`icon-fintube*.svg`)

## 이미지는 지면과 같은 원본을 쓴다

```
capture_ui.py → build_assets.py → 홍보자료/assets/*.png → build_site_assets.py → assets/*.webp
```

`_scripts/build_site_assets.py` 를 돌리면 지면(리플릿·잡지면)이 쓰는 PNG 에서 웹용 WebP 를
다시 만든다. **화면을 재촬영하면 지면과 이 페이지를 함께 갱신할 것** — 따로 만들면 어긋난다.
크기는 HTML 의 `width`/`height` 속성과 짝이므로 바꿀 때 양쪽을 같이 고친다.

## GitHub Pages 게시

1. 이 폴더를 **새 저장소**로 `git init` (개발 저장소를 복사하지 말 것 — 히스토리에 소스가 남습니다)

3. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`

## 한국어 / English 전환 (2026-09-17)

**`index.html`(데스크톱)과 `m.html`(모바일)이 `site-i18n.js` 한 벌을 함께 쓴다.**
두 판은 문구가 같아야 하는데 사전을 두 벌 두면 반드시 갈라지기 때문이다.

- 화면 문구에 `data-i18n="키"` 를 달고 **영문만** `site-i18n.js` 의 `EN` 사전에 적는다.
  한국어는 각 페이지의 HTML 원문을 첫 실행 때 그대로 떠서 쓰므로 **번역문을 두 벌 관리하지 않는다**.
- 헤더 오른쪽 `EN`/`한국어` 버튼으로 바꾸고, 선택은 `localStorage['hx-site-lang']` 에 남는다.
  처음 방문이면 브라우저 언어가 한국어가 아닐 때만 영문으로 연다.
- 페이지는 `<body data-page="desktop|mobile">` 로 자신을 알린다(제목·설명이 판마다 다르다).
- 판마다 마크업이 다른 몇 개는 `EN_M`(모바일 전용)으로 덮는다 —
  ⚠️ `m.html` 에는 `--text-muted` 토큰이 없어 데스크톱 값의 인라인 style 을 그대로 쓰면 색이 먹지 않고,
  히어로 tagline 은 모바일만 줄바꿈이 있다.
- 문구를 **추가**하면 `data-i18n` 키와 `EN` 항목을 **같이** 넣을 것. 사전에 없는 키는 영문에서도
  한국어가 그대로 보인다(깨지지는 않는다). 사전 값은 `innerHTML` 로 들어가므로 표시용 태그만 쓴다.
- 전환 버튼은 CSS 에서 감춰 두고 `site-i18n.js` 가 켠다 — 스크립트가 못 뜨면 죽은 버튼이 남기 때문이다.

### 반응형 주의 (실측으로 잡은 것)

영문은 문구가 길어 헤더가 먼저 무너진다. `html[lang="en"]` 전용 규칙으로 센터명·메뉴를 한 단계
일찍 감추고, 좁은 폭에서는 여백을 줄인다.

- ⚠️ `.brand img` 는 `flex:0 0 auto` 라 **줄지 않고 넘쳐서 메뉴를 덮는다** — 폭이 모자라면 감춰야 한다.
- ⚠️ 모바일 320px 영문은 버튼 글자('한국어')가 'EN' 보다 넓어 넘쳤다 → 그 폭에서는 헤더 버튼을 접는다.
- 확인 범위: 데스크톱 1440~390px 12개 폭, 모바일 320~640px 6개 폭, 각각 한/영 양쪽 · 콘솔 오류 0.

## 모바일 자동 전환

`index.html` 의 `<head>` 맨 앞 스크립트가 **좁은 화면 또는 모바일 UA** 면 `m.html` 로 넘긴다.

- `m.html` 하단의 **데스크톱 버전 보기** 링크는 `index.html?desktop=1` 로 들어와
  `sessionStorage['hx-view']='desktop'` 을 남긴다 → 그 세션 동안 자동 전환이 꺼진다.
- ⚠️ **`m.html` 은 반대 방향 자동 전환을 하지 않는다.** 두 페이지가 서로 넘기면 루프가 된다.
